# VideoDownloader

A simple application for downloading videos from Instagram and YouTube. This project utilizes `yt-dlp`, a powerful tool for downloading videos from a wide variety of websites.

## Features

- **Instagram Video Downloading**: Download videos from Instagram using the Instagram video URL.
- **YouTube Video Downloading**: Support for downloading videos from YouTube (currently being worked on).
- **Simple Interface**: Easy-to-use interface for seamless video downloading.

## Installation

1. Clone this repository to your local machine:

    ```bash
    git clone https://github.com/HellDeadShot/VideoDownloader.git
    cd VideoDownloader
    ```

2. Install the required dependencies:

    ```bash
    pip install -r requirements.txt
    ```

    (Make sure you have Python 3.7+ installed.)

3. Install `yt-dlp` if it isn't in the requirements:

    ```bash
    pip install yt-dlp
    ```

## Usage

1. Run the `VideoDownloader` application.

2. Paste the video URL (Instagram or YouTube) into the input field.

3. Click the **Download** button to start downloading.
